# Visual review

Review the original and edit together. A beautiful unrelated scene fails. These checks are visual judgements; no percentage score or pixel metric establishes game fidelity.

## Shared checks

- Composition: same aspect ratio, viewpoint, important landmarks and approximate screen locations.
- Content: same principal subjects, object classes and counts; no substituted vehicle or invented foreground character.
- Character: pose, held object, clothing palette and silhouette preserved. Realistic mode checks likeness and anatomy; block mode checks recognisable coarse cues.
- Whole-scene treatment: geometry, surface detail and lighting follow the same recipe; no photographic subject pasted into a stylized background.
- No accidental labels, HUD, logo, watermark or malformed hands.

## Minecraft

Required: cuboid architecture and character, coarse coherent construction grid, distinct square low-resolution texels on block faces, simple matte lighting. Inspect floor and windows for shader-like reflections, coat for smooth fabric, foliage for photographic leaves. Non-vanilla objects may be artistic block-built equivalents; mention them when relevant.

## Cyberpunk

Required: scene-appropriate design language, deliberate 3D hard-surface and material rebuilding, physically coherent light / reflections, stable original subject. Inspect daylight conversion for unrequested night, large additions for scene drift, portrait for changed face or pose. A quiet courtyard can have fewer signature cues than a commercial street; describe this honestly rather than dressing it in arbitrary neon.

## Decision

- Ready: key requirements visible and original recognisable. Report any minor approximation.
- Revise: a specific major miss has a plausible correction. Repeat the original invariants and correct that miss.
- Unresolved: after two targeted repairs a key miss remains. Return a clearly labelled draft and state the limitation; do not call it validated.

For publishing a new recipe, use at least two different photographic scene types with actual image-input edits. Retain prompts, failed attempts, final artifacts and concrete review notes. This is a small manual check, not a statistically representative evaluation or a guarantee for future generations.
