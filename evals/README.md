# 实际编辑与目测记录

2026-10-05，使用 Codex 内置图片工具。所有编辑都传入了对应的本地原始 PNG；不是根据一段照片描述另画一张。公开展示是 960×640 JPEG，原始生成文件保留在本地。没有使用用户私人照片或提取游戏贴图。

院落输入复用此前 Source Engine Photo 项目的合成测试照片；街景输入新生成，包含一位虚构成年人、雨衣、伞、树、咖啡馆、公交站和远处车辆。具体提示在 [prompts.json](prompts.json)，图像 SHA-256 与结果记录在 [results.json](results.json)。哈希用于识别测试文件，不表示相似度。

## 采用的结果

| 场景 / 预设 | 看见的结果 | 仍有的近似 |
| --- | --- | --- |
| 院落 / Minecraft，第二次 | 门、窗、长椅、自行车仍在原位；墙地面按大块面重建，植物和道具变为方块形 | 门、自行车是艺术化方块道具，贴图为生成的近似，不能证明原版资产一致 |
| 街景 / Minecraft，第二次 | 人物、雨衣颜色、伞和街道位置保留；树、人物、窗和建筑重建；地面反射被去掉 | 玩家化改变了精细身份与比例，衣服仍有少量几何厚度；不是引擎实际渲染 |
| 院落 / Cyberpunk，第二次 | 门窗、长椅与车保持原关系；墙改为工业面板，管线与实体灯有用途，保持白天 | 安静工业院落的游戏辨识度弱于商业街；没有独有地标，不保证单凭此图能认出游戏 |
| 街景 / Cyberpunk，第一次 | 主角面部、姿势和衣服颜色近似保留；场景加入功能性改造，灯源与湿地反射对应 | 远景结构比原图更密，人物脸仅目测近似；并非精确身份验证 |

判定是创建者助手按[检查条件](../skills/game-photo-mode/references/review.md)做的视觉判断。没有第二位独立评审，没有真实用户照片测试，也没有“相似度 99%”一类测量。发布的是可复用编辑流程及其证据，不是结果一致性的保证。

## 复现和继续测试

在支持图片编辑的宿主里提供原图，读取相应 recipe，将原图观察写进提示并执行实际编辑。这里的精确提示是测试记录，不应直接把“门、窗、自行车”套进每张用户照片。模型输出具有随机性，重复提示不能保证得到相同图。

下一轮有意义的测试：自然风景、室内、近景人脸、多人、文字与复杂手部。新增游戏至少覆盖两类场景，先记录失配，再修正；无法达到目标则保留实验状态。
